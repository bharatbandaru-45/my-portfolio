# BCA Student Portfolio

A responsive, dark-modern personal portfolio made with beginner-friendly HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and sections
- `style.css` — dark theme, layout, and responsive styles
- `script.js` — mobile navigation and current year
- `assets/` — place your images here

## Personalize before publishing

Open `index.html` and replace:
- `Your Name` with your name
- `Your College Name` with your college
- `your.email@example.com` with your email
- GitHub and LinkedIn links with your profile URLs
- Sample project cards with your actual projects

You can also update the page title and description in the `<head>` section.

## Preview on your computer

1. Extract the ZIP file.
2. Open the `professional-bca-portfolio` folder.
3. Double-click `index.html` to open it in a browser.

For easier editing, open the folder in Visual Studio Code.

## Publish free with GitHub Pages

1. Sign in at https://github.com/ and create a **Public** repository, for example `my-portfolio`.
2. In the repository, choose **Add file → Upload files**.
3. Upload the contents of this folder (make sure `index.html` is in the repository root, not inside another nested folder).
4. Select **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a few minutes. Your site address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/my-portfolio/`

If you name the repository `YOUR-GITHUB-USERNAME.github.io`, the site address will instead be:
`https://YOUR-GITHUB-USERNAME.github.io/`

## Tips

- Keep project descriptions honest and add only work you have actually done.
- Do not publish passwords, private phone numbers, home addresses, or other sensitive information.
- Test the site on both mobile and desktop before sharing it.
